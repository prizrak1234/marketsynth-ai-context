# P1.2 Mapping contract

Version: `implementation_to_marketing_plan.v1`

| Source | Target |
|--------|--------|
| ImplementationPlan.title | MarketingPlan.title |
| ImplementationPlan.summary / objective | MarketingPlan.goal |
| Eligible ImplTask | MarketingSpecialistTask |

Mapped task fields: title/description → objective; expected_output; acceptance criteria folded into expected_output (degraded); supported roles only.

Not mapped: task lifecycle, local approvals, budget gates, roadmap dates, Client Owner / CEO / PM / Performance Marketer as executable specialists.

Classifications: exact | transformable | excluded | unsupported | blocked.
