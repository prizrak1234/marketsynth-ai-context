# Specialist Expertise UI

User-facing Specialist Activity card shows:

- Specialist name
- Task
- **Экспертиза** (expertise actually used by the skill)
- Materials used (knowledge count, policies)
- Status / review status

Technical terms (`skills`, `prompt`, `tool profile`) are reserved for
owner/admin diagnostics.

Component: `web/src/components/workspace/home/specialist-activity-card.tsx`.

Reject. No publish.
