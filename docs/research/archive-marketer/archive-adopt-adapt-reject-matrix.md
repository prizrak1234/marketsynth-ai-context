## REJECT AS WRITTEN (must not pass validators)

| Phrase / pattern | Reason |
|------------------|--------|
| Guaranteed earnings / exact income | Financial claim without evidence |
| «Стабильный дополнительный доход +X%» | Unsupported outcome (archive example) |
| «100% безопасность» | Safety guarantee without basis |
| «100% результат» / «100% работоспособность» | Outcome guarantee |
| «Технология не может не сработать» | False certainty |
| «Железобетонный аргумент» | Rhetoric as proof |
| «400% уверенности» | Manipulative confidence |
| «Клиент 100% согласится на сделку» | Assumption as fact |
| Fictitious proof / invented statistics | Evidence integrity |
| Unsupported competitor superiority | Comparative claim without basis |
| Manipulative risk suppression | Compliance / trust |
| Presenting assumptions as customer truth | CIM / evidence invariant |
| Crypto-trading examples as approved claims | Regulated / high-risk domain |
