# Accepted limitations

See `packages/knowledge/kb_wpl_program/0.1.0/accepted_limitations.json`.

Key limitations:

- No Knowledge Core persistence
- No API/UI for discovery or linking
- No vector search or LLM routing
- No runtime execution or Connector activation
- No Skill Generator or external Skill search
- No presentation renderer or n8n deployment gateway
- Legacy `app/knowledge/linking/` remains
- Discovery alias catalog is finite and manually governed
