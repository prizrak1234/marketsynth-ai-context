# Controlled pilot success metrics

Track outcomes that measure trust and operability — not vanity usage.

| Metric | Intent |
|--------|--------|
| Projects completed (Brief → … → MarketingPlan draft) | End-to-end utility |
| % reaching approved Verdict | Decision usefulness |
| Median time to complete intake/Brief | Friction |
| Blocking UX defects (P0/P1) filed | Quality |
| Login / session failure rate | Auth reliability |
| Data-loss incidents | Integrity |
| Owner-isolation incidents | Security |
| Restore / backup incidents | Recoverability |
| User comprehension of Verdict (qualitative) | Honesty of product |
| User trust in evidence traceability (qualitative) | Core promise |
| % of users who accept NO_GO / CONDITIONAL_GO as fair | Trust in gates |
| Support burden (tickets / hours per user) | Operational cost |

Do **not** optimize for DAU, message count, or Agent Runs (forbidden in this pilot).
