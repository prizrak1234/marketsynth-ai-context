# Integration I7 — MVP definition

Based on **actual code**, not generic SaaS checklists.

## MVP REQUIRED (honest commercial path)

1. Authentication (API key / user) — **exists**
2. Real Project SoT — **exists**
3. Real Intake persistence beyond name/description — **gap P0**
4. Durable Investigation — **gap P0**
5. Durable Source + Evidence — **gap P0**
6. Business Verdict persistence + human review — **gap P0**
7. Strategy persistence (≠ MarketingPlan) — **gap P0**
8. MarketingPlan handoff to draft specialist plan — **gap P1** (preview exists)
9. Read-only Control Center — **exists** (campaign ops)
10. External execution **optional** for first commercial MVP — intentionally exclusive until Verified Execution

## MVP OPTIONAL

Automated research · live agent workforce · providers · real publication · budget changes · `execution_mode` (AI.592) · PDF export · collaboration

## MVP OUT OF SCOPE

Full autonomous agency · unrestricted real execution · multi-provider publishing · complex billing · real-time multi-user collab

## Commercial MVP definition (I7)

> Authenticated owner can create a Project, complete an Intake that persists, run Investigation with real Source/Evidence, record a durable Business Verdict, persist Strategy, and (explicitly) create a **draft** MarketingPlan handoff — with Control Center visibility — **without** requiring real provider execution.

Until P0 domains exist, Product Alpha remains a **UX baseline over labelled local previews**, not a truthful commercial SoT.
