# Project creation policy (Phase H1)

## Required (route to Project Intake)

- idea_validation
- market_research
- competitor_analysis
- marketing_strategy
- saas (substantial product planning)
- automation when treated as multi-step delivery (H1 marks `requires_project=true`)

## Optional / specialist-first (no auto Project)

- content
- content_plan
- social_media
- youtube
- telegram_bot
- concrete website/landing once type is known

## Never auto-create Project on clarify

Clarification must complete before Project Intake / specialist handoff links are offered as executable next steps beyond answering.
