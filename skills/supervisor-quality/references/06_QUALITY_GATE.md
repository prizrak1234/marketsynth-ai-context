# Quality Gate — 3 теста перед запуском скилла

## Зачем это нужно

Скилл с плохим триггером:
- Срабатывает когда не надо → раздражает
- Не срабатывает когда надо → бесполезен

Quality Gate занимает 3 минуты. Экономит недели раздражения.

---

## Три теста

```
Тест 1 (позитивный): промпт который ДОЛЖЕН запустить скилл → проверь ✅
Тест 2 (позитивный): другой промпт который тоже должен   → проверь ✅
Тест 3 (негативный): промпт который НЕ должен запускать  → убедись ❌
```

Все три прошли? Скилл готов к работе.
Хоть один провален? Чинишь триггер прежде чем использовать.

---

## Промпт для запуска Quality Gate

```
Проведи Quality Gate для скилла [название].

Прочитай его description из ~/.claude/skills/[название]/SKILL.md

Тест 1 (позитивный): отправь запрос "[промпт который должен триггерить]"
→ сработал скилл? Да/Нет

Тест 2 (позитивный): отправь запрос "[другой промпт]"
→ сработал скилл? Да/Нет

Тест 3 (негативный): отправь запрос "[промпт который НЕ должен]"
→ скилл НЕ сработал? Да/Нет

Результат:
✅ Все три прошли — скилл готов
⚠️ Тест [N] провалился — нужно исправить description скилла

Если есть проблемы — предложи исправленную версию description.
```

## Примеры Quality Gate для разных типов скиллов

### Для контентного скилла (igor-tone)

```
Тест 1: "напиши в моём стиле хук про n8n"        → должен сработать ✅
Тест 2: "используй мой голос для Reels-сценария"  → должен сработать ✅
Тест 3: "что такое тон голоса в музыке"           → НЕ должен ❌
```

### Для аналитического скилла (youtube-analyzer)

```
Тест 1: "проанализируй это видео: [URL]"          → должен сработать ✅
Тест 2: "сделай выжимку YouTube-видео"            → должен сработать ✅
Тест 3: "как называется этот YouTuber"            → НЕ должен ❌
```

### Для технического скилла (code-reviewer)

```
Тест 1: "сделай code review этого файла"          → должен сработать ✅
Тест 2: "проверь мой diff перед коммитом"         → должен сработать ✅
Тест 3: "какой код лучше Python или JS"           → НЕ должен ❌
```

## Как починить триггер если тест провалился

**Проблема: скилл НЕ срабатывает (позитивный тест провален)**

Description слишком узкий. Расширь:
```
Было:    "Analyze YouTube videos. Trigger: youtube analyze"
Стало:   "Analyze YouTube videos and create summaries. Trigger when user
          shares YouTube URL, asks to analyze/summarize video, or mentions
          YouTube analysis."
```

**Проблема: скилл срабатывает когда не надо (негативный тест провален)**

Description слишком широкий. Добавь ограничения:
```
Было:    "Write content in Igor's style"
Стало:   "Write content in Igor's style for social media posts, hooks, and
          scripts. Trigger: 'в моём стиле', 'используй мой тон', 'igor-tone'.
          DO NOT trigger for general writing questions or explanations."
```

## Чеклист перед запуском скилла

- [ ] Написал description в одном предложении (конкретно что делает и когда)
- [ ] Указал триггерные фразы явно
- [ ] Указал "DO NOT trigger when..." для граничных случаев
- [ ] Прошёл 2 позитивных теста
- [ ] Прошёл 1 негативный тест
- [ ] Добавил минимум 2 реальных примера в скилл
- [ ] Добавил критерии хорошего результата
- [ ] Создал пустой feedback.log для будущего фидбека

## Промпт для batch-тестирования всех скиллов

```
Проведи Quality Gate для всех моих скиллов.

Для каждого скилла в ~/.claude/skills/:
1. Прочитай description
2. Придумай 2 промпта которые должны его запустить и 1 который не должен
3. Симулируй — запустил бы агент этот скилл?
4. Выдай результат:

---
Quality Gate Report — [дата]

✅ ПРОШЛИ:
- [скилл]: триггеры точные

⚠️ ТРЕБУЮТ ПРАВКИ:
- [скилл]: [что не так с триггером]

Рекомендации:
- [скилл]: исправить description на "[новая версия]"
---
```
