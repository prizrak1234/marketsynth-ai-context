# Шаг 6: Чек-лист проверки

Проверь, что система реально собрана, а не только описана.

## Базовая настройка

- [ ] `KIE_AI_KEY` добавлен в `.env` (именно `KIE_AI_KEY`, не `KIE_API_KEY`)
- [ ] `source .env && echo $KIE_AI_KEY` выводит ключ (не пусто)
- [ ] Директория `workspace/output/images/` существует
- [ ] Директория `workspace/library/image-assets/` существует
- [ ] `registry.json` создан (хотя бы с пустым `{ "faces": [], "templates": [], "styles": [] }`)

## Skill и runtime

- [ ] Есть skill для image-generation с правильным выбором модели
- [ ] Дефолтная модель — `gpt-image-2-text-to-image` (не nano-banana-2)
- [ ] nano-banana-2 выбирается только при явном "быстро" / "черновик"
- [ ] Короткий промпт автоматически расширяется (молча, без уведомления)
- [ ] Простой запрос НЕ создаёт отдельный агент
- [ ] Сложный запрос (3+ вариантов, серия) эскалирует в image-creator агента

## Обработка изображений

- [ ] Одно прикреплённое фото → image-to-image напрямую (не эскалация)
- [ ] Два и более фото → все в input_urls через Telegram URL конвертацию
- [ ] Локальный файл корректно конвертируется в публичный URL через Telegram API

## Генерация и доставка

- [ ] Polling работает с таймаутом 3 мин (не бесконечный цикл)
- [ ] После `state: "success"` файл скачивается и проверяется (`ls -lh`)
- [ ] Не отправляется "готово" пока файл физически не существует
- [ ] Telegram-ответ работает (sendPhoto для превью, sendDocument для финала)

## Тестовые запросы (прогнать по порядку)

1. Простой текстовый запрос:
   ```
   Создай обложку для видео про ИИ, синий неон, 16:9
   ```
   Ожидание: gpt-image-2-text-to-image, файл в workspace/output/images/, фото в Telegram

2. Запрос с "быстро":
   ```
   Быстро набросок: робот с ноутбуком
   ```
   Ожидание: nano-banana-2, результат за 25-40 сек

3. Image-to-image (прикрепить любое фото):
   ```
   Возьми это фото и сделай из него YouTube thumbnail в tech-стиле
   ```
   Ожидание: gpt-image-2-image-to-image, файл через 60-90 сек

4. Несколько вариантов:
   ```
   Сделай 3 варианта обложки для видео про Claude Code
   ```
   Ожидание: эскалация к image-creator агенту
