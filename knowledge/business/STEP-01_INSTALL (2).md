# Шаг 1 — Установка планировщика

Все команды выполняются на VDS через SSH.

## Что нужно

- VDS/VPS с Ubuntu 22.04+
- SSH-доступ
- Рабочий ИИ-агент на базе ClaudeClaw (или аналога с Node.js)
- pm2 установлен и агент запущен

## Команды

### 1. Проверяем что агент запущен

```bash
pm2 list
```

Должны видеть процесс со статусом `online`. Если нет — сначала запустите агента.

### 2. Собираем проект (если dist/ нет или устарел)

```bash
cd ~/claudeclaw   # или папка вашего агента
npm run build
```

### 3. Проверяем наличие планировщика

```bash
ls dist/ | grep schedule
```

Должно показать:
```
schedule-cli.js
scheduler.js
```

Если файлов нет — планировщик не входит в вашу версию. Обновите репозиторий:
```bash
git pull
npm install
npm run build
```

### 4. Смотрим список задач

```bash
node dist/schedule-cli.js list
```

Если пусто — всё хорошо, сейчас добавим задачи.

## Примечание

Планировщик запускается автоматически вместе с основным процессом бота.
Отдельно ничего запускать не нужно — он живёт внутри pm2-процесса.
