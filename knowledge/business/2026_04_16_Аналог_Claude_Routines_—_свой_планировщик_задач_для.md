### Блок 1 — Теория: что такое планировщик (1:30–4:00)

**Что объясняем:**

Cron — это системный таймер на любом Linux-сервере. Работает 24/7. Запускает команды по расписанию.

Формат cron-строки:
```
┌─ минута (0-59)
│  ┌─ час (0-23)
│  │  ┌─ день месяца (1-31)
│  │  │  ┌─ месяц (1-12)
│  │  │  │  ┌─ день недели (0-7, где 0 и 7 = воскресенье)
│  │  │  │  │
*  *  *  *  *
```

**Примеры показываем на слайде/заметке:**
```
0 9 * * *        → каждый день в 9:00
0 9 * * 1        → каждый понедельник в 9:00
0 */4 * * *      → каждые 4 часа
0 9,18 * * *     → в 9:00 и 18:00 каждый день
0 10 * * 3       → каждую среду в 10:00
*/30 * * * *     → каждые 30 минут
```

Наш schedule-cli.js — это удобная обёртка над этой системой. Вместо того чтобы лезть в crontab вручную, даёшь промпт и расписание одной командой.

### Блок 3 — Как это устроено под капотом (7:00–10:00)

**Показываем архитектуру (можно нарисовать схему):**

```
pm2 (держит процесс живым)
    └── scheduler.js (проверяет cron каждую минуту)
            └── schedule-cli.js (управление через терминал)
                    └── bot.ts (выполняет промпт → Telegram)
```

**Ключевые моменты:**
- pm2 — это как системный демон. Если сервер перезагрузится, pm2 поднимет бота автоматически
- scheduler.js живёт внутри бота, отдельный процесс запускать не нужно
- Состояние задач хранится в SQLite — переживает перезагрузки
- Промпт выполняется как обычное сообщение в боте, результат летит в Telegram

**Сравнение с Claude Routines:**

| | Claude Routines | Наш scheduler |
|---|---|---|
| Лимит запусков | Pro: 5/день | Без лимита |
| Минимальный интервал | 1 час | Хоть каждую минуту |
| GitHub нужен | Да | Нет |
| Stateless | Да | Нет — помнит контекст |
| Ваш сервер | Нет | Да |
| Стоимость | Входит в план | VDS ~$6/мес |
| Настройка | Через веб-интерфейс | Одна команда |

### Блок 6 — Управление задачами (26:00–30:00)

**Пауза задачи (например, уехал в отпуск):**

### Блок 7 — Лайфхаки и реальные примеры использования (30:00–34:00)

**5 реальных задач которые можно поставить сразу:**

1. **Дайджест YouTube-inbox** — раз в неделю бот проверяет папку с ссылками и анализирует их
   ```
   Schedule: 0 9 * * 1  (каждый понедельник)
   ```

2. **Напоминание о checkpoint** — каждую пятницу в 17:00 бот напоминает сохранить итоги недели
   ```
   Schedule: 0 17 * * 5
   ```

3. **Автопостинг контента** — бот генерирует пост для Threads раз в день и ждёт одобрения
   ```
   Schedule: 0 10 * * *
   ```

4. **Мониторинг крипты** — каждые 2 часа проверяет цену и сигналит при отклонении
   ```
   Schedule: 0 */2 * * *
   ```

5. **Еженедельный отчёт** — каждое воскресенье компилирует что сделано за неделю
   ```
   Schedule: 0 20 * * 0
   ```

**Важный лайфхак — промпты для планировщика:**
- Пишите конкретно: что проверить, что сделать, что сообщить
- Добавляйте условие "если нечего сообщать — промолчи" чтобы не спамить
- Для длинных задач лучше давать путь к скрипту: `node scripts/имя.js`
- Тестируйте промпт сначала вручную, потом ставьте в scheduler
