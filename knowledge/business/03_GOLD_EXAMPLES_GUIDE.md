# Золотой датасет — как создать примеры для скилла

## Зачем это нужно

Примеры — это главное что отличает живой скилл от мёртвого.

Без примеров агент интерпретирует слова "коротко", "в моём стиле", "хорошо" по-своему каждый раз. С примерами — сравнивает свой результат с эталоном.

**3 реальных примера = +30-40% стабильности результата.**

---

## Откуда брать примеры

**Лучшие источники:**
- Результаты которые ты уже одобрил и использовал
- Посты/тексты которые хорошо сработали (высокий охват, реакции)
- Ответы агента которые тебя реально порадовали — сохраняй их сразу
- Твои собственные тексты, написанные вручную в лучшей форме

**Не использовать:**
- Придуманные примеры "как должно быть"
- Примеры из чужих стилей
- Результаты которые ты правил больше двух раз

---

## Промпт для создания золотого датасета

Отправь агенту:

```
Помоги мне создать золотой датасет для скилла [название].

Задача скилла: [что он делает]

Шаг 1. Найди в этих местах подходящие примеры:
- [папка с архивом / Obsidian / файлы] — ищи лучшие результаты
- [другой источник если есть]

Шаг 2. Отбери 3-5 примеров по критериям:
- Результат реально хорош (не просто приемлем)
- Соответствует тому что я хочу получать от скилла
- Разные по типу задачи (чтобы охватить разные кейсы)

Шаг 3. Для каждого примера оформи пару:
Вход: [что пришло на вход]
Выход: [лучший результат]

Шаг 4. Добавь эти пары в раздел "## Примеры (золотой датасет)"
в файл ~/.claude/skills/[название]/SKILL.md

После добавления — покажи обновлённый раздел для проверки.
```

---

## Промпт для обновления примеров после хорошего результата

Когда агент выдал что-то реально хорошее — сразу сохраняй:

```
Вот этот результат мне понравился:
[вставь результат]

Добавь его в золотой датасет скилла [название] как Пример [N].
Входом была задача: [опиши задачу]
Сохрани в ~/.claude/skills/[название]/SKILL.md в раздел "## Примеры"
```

---

## Три типа примеров которые нужны

**Тип 1: Базовый кейс**
Самая типичная задача для этого скилла. Стандартный вход — эталонный выход.

**Тип 2: Сложный кейс**
Задача с нюансами или ограничениями. Показывает как скилл справляется с нестандартным.

**Тип 3: Граничный кейс**
Задача на грани применимости скилла. Показывает где скилл заканчивается.

## Пример: золотой датасет для контентного скилла

```markdown
## Примеры (золотой датасет)

### Пример 1 — Хук для поста про инструмент

Вход:
> Напиши хук для поста про то, что я перешёл с n8n на Claude Code

Выход:
> Я удалил n8n. Вот почему это было лучшее решение за год.

---

### Пример 2 — Хук с цифрой

Вход:
> Напиши хук для поста про автоматизацию контента

Выход:
> Мой контент-план на месяц — 40 минут работы. Остальное делает Claude.

---

### Пример 3 — Хук-провокация

Вход:
> Напиши хук для поста про то, что большинство AI-инструментов бесполезны

Выход:
> 90% AI-инструментов которые ты установил — не работают. И это не их проблема.
```

---

## Как поддерживать датасет актуальным

- После каждого результата который тебя порадовал — добавь в примеры
- Раз в месяц — проверь примеры: всё ещё актуальны?
- Если стиль изменился — замени старые примеры на новые
- Максимум 7 примеров. Больше не нужно — агент теряет фокус.
