# Demo Prompts — Живые Skills vs Мёртвые файлы

Это набор точных промптов для демонстраций из видео.  
Скопируй нужный блок и отдай своему агенту.

---

## 1. Аудит существующих skills

```text
Проведи аудит всех моих skills.

Для каждого skill определи:
1. Он слишком общий или достаточно узкий?
2. Есть ли у него критерии качества?
3. Есть ли реальные эталоны или примеры?
4. Есть ли память ошибок / фидбека?
5. Есть ли механизм controlled update?

Верни таблицу:
- skill
- уровень зрелости 1-4
- главная слабость
- что улучшить первым

В конце:
- какие 3 skills у меня сейчас самые слабые
- какие 3 дадут самый быстрый выигрыш при улучшении
```

---

## 2. Слабый content skill — прогон "было"

```text
Используй простой skill для создания Reels.

Задача:
Сделай Reels-сценарий по этой заметке.

Требования:
- 60-80 секунд
- коротко
- понятно

Верни 1 вариант.
```

---

## 3. Living content skill — прогон "стало"

```text
Используй living content skill.

Открой 15 последних approved Reels из Archive.
Вытащи:
- силу первого хука
- ритм сцен
- длину блоков
- тип CTA
- запрещённые формулировки

После этого создай 3 Reels-сценария по этой заметке.

Требования:
- длительность 60-80 секунд
- 6-10 сцен
- разговорный русский
- сильный первый заход
- numeric CTA если он уместен

Верни:
1. хук
2. сцены
3. черновой текст
4. почему это похоже на мой стиль
```

## 4. Слабый review — прогон "было"

```text
Проверь этот код и скажи что думаешь.
```

---

## 5. Сильный review — прогон "стало"

```text
Выступи как code-reviewer.

Проверь этот diff только на:
- баги
- поведенческие регрессии
- edge cases
- пропущенные тесты

Не пересказывай код.
Для каждой находки дай:
1. в чём риск
2. к чему это приведёт
3. как исправить

Верни:
- findings
- open questions
- overall risk
```

```text
Сделай исследование того, что происходит в AI agents.
```

## 7. Сильный research — прогон "стало"

```text
Используй research skill.

Возьми последние 10 заметок из папки YouTube по теме AI agents.
Сделай только следующее:
- найди повторяющиеся сигналы
- отдели хайп от реально внедряемых вещей
- верни 5 практических выводов
- верни 3 темы для контента

Не делай длинный пересказ.
Не перечисляй всё подряд.
Нужен только сигнал и прикладной вывод.
```

## 8. Self-learning loop

```text
Используй living skill loop.

После выполнения задачи:
1. Спроси меня: "Результат 1-5? Что улучшить одной фразой?"
2. Запиши ответ в feedback-log.jsonl
3. Если есть конкретная правка:
   - сравни её с последними 5 записями
   - найди повторяющиеся сигналы
   - добавь подтверждённый паттерн в learned-patterns.md
4. Не переписывай SKILL.md сразу
5. Если сигнал повторился 3+ раза:
   - создай запись в pending-updates.md

Покажи:
- что записал
- какой паттерн извлёк
- нужно ли обновлять ядро
```
