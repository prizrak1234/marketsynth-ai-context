# 50+ идей для планировщика ИИ-агента по нишам

Всё это настраивается одной командой через schedule-cli.js.
Формат: `node dist/schedule-cli.js create "ПРОМПТ" "CRON" CHAT_ID`

---

## Для самого ИИ-агента (системные задачи)

Это самое ценное — агент сам себя обслуживает.

**Автосохранение сессии каждые 10 сообщений**
```
Schedule: */15 * * * *  (каждые 15 минут)
Промпт: "Проверь текущую сессию. Если было 10+ сообщений с последнего сохранения —
         сохрани summary сессии в obsidian-vault/Sessions/auto/ с датой и временем.
         Если меньше — промолчи."
```

**Еженедельная дефрагментация памяти**
```
Schedule: 0 3 * * 0  (воскресенье в 3:00 ночи)
Промпт: "Запусти node scripts/dream.js для консолидации памяти. Сообщи сколько
         воспоминаний обработано."
```

**Группировка и чистка старых заметок**
```
Schedule: 0 2 1 * *  (1-е число каждого месяца в 2:00)
Промпт: "Просмотри obsidian-vault/Sessions/ за прошлый месяц. Найди дублирующиеся
         темы, создай сводную заметку по каждой теме. Удали дубли старше 30 дней."
```

**Автопроверка здоровья системы**
```
Schedule: 0 8 * * 1  (каждый понедельник в 8:00)
Промпт: "Системный чек-ап: 1) pm2 list — все процессы online? 2) диск — сколько места
         свободно? 3) eval.js stats — ошибки за неделю? Сообщи результат кратко."
```

**Архивирование завершённых задач**
```
Schedule: 0 23 * * *  (каждый день в 23:00)
Промпт: "Проверь workspace/tmp/ — удали файлы старше 7 дней. Перенеси завершённые
         progress-*.md в архив. Сообщи что убрал."
```

**Обновление wiki базы знаний**
```
Schedule: 0 4 * * 0  (воскресенье в 4:00)
Промпт: "Запусти node scripts/wiki-compile.js --scan. Сообщи сколько статей обновлено
         и какие новые темы появились."
```

**Напоминание сделать /compact**
```

Промпт: "Проверь размер текущего контекстного окна через convolife. Если больше 60% —
         напомни сделать /compact. Если меньше — промолчи."
```

## Как добавить свою идею

1. Придумайте что должен делать агент
2. Определите расписание (см. шпаргалку в CRON_CHEATSHEET.md)
3. Напишите промпт конкретно: что проверить, что сделать, что сообщить
4. Добавьте условие "если нечего — промолчи" где нужно
5. Запустите командой:

```bash
node dist/schedule-cli.js create "ВАШ ПРОМПТ" "CRON" CHAT_ID
```

Проверьте: `node dist/schedule-cli.js list`
