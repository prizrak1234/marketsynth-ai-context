# 20 задач для делегирования агенту по нишам

Каждая задача — с готовым промптом и расписанием.
Скопируй промпт в шаблон агента и запусти.

---

## Для всех: системные задачи агента

### 1. Утренний дайджест
**Расписание:** каждый день 07:00 МСК (04:00 UTC) → `0 4 * * *`
```
Прочитай ~/obsidian-vault/Inbox/ и ~/obsidian-vault/Sessions/ за вчерашний день.
Составь дайджест: что сделано, что не закрыто, что требует решения.
Отправь в Telegram. Сегодня {ДАТА}.
```

### 2. Дефрагментация памяти
**Расписание:** 2 раза в день → `23 6,18 * * *`
```
Запусти bash /root/claudeclaw/scripts/dream.sh
Сообщи сколько воспоминаний обработано.
```

### 3. Еженедельный аудит системы
**Расписание:** каждый понедельник 02:00 UTC → `0 2 * * 1`
```
Сравни ~/.claude/agents/ и ~/.claude/skills/ с ~/obsidian-vault/ClaudeClaw/changelog.md.
Найди что есть на диске но не задокументировано. Отправь отчёт в Telegram.
```

### 4. Поиск автоматизаций (Automation Advisor)
**Расписание:** каждое воскресенье 21:00 UTC → `0 21 * * 0`
```
Прочитай session notes за последние 7 дней из ~/obsidian-vault/Sessions/.
Найди задачи которые повторялись 2+ раза. Предложи топ-3 для автоматизации
с готовыми промптами. Отправь в Telegram.
```

## Для предпринимателей и фрилансеров

### 5. Мониторинг Gmail по ключевым словам
**Расписание:** каждые 2 часа → `0 */2 * * *`
```
Проверь Gmail через gws gmail users messages list за последние 2 часа.
Найди письма с темой содержащей: [ТВОИ КЛЮЧЕВЫЕ СЛОВА].
Если нашёл — перешли краткое содержание в Telegram.
Если не нашёл — молчи.
```

### 6. Еженедельный отчёт по проектам
**Расписание:** пятница 17:00 МСК → `0 14 * * 5`
```
Прочитай ~/obsidian-vault/Projects/ -- папки изменённые за эту неделю.
Составь краткий статус по каждому проекту: что сделано, что зависло, что на следующей неделе.
Отправь в Telegram.
```

### 7. Дайджест платежей и задолженностей
**Расписание:** 1-е число месяца 09:00 МСК → `0 6 1 * *`
```
Прочитай ~/obsidian-vault/Finance/ за прошлый месяц.
Составь: итого получено, итого расходов, кто должен, что не оплачено.
Отправь сводку в Telegram.
```

### 8. Напоминание о регулярных задачах
**Расписание:** каждый понедельник 09:00 МСК → `0 6 * * 1`
```
Прочитай ~/obsidian-vault/Recurring/ -- список регулярных задач.
Найди задачи с тегом "еженедельно". Отправь напоминание в Telegram
с их списком и статусом выполнения.
```

## Для создателей контента

### 9. Парсинг идей для контента
**Расписание:** каждый день 08:00 МСК → `0 5 * * *`
```
Прочитай ~/obsidian-vault/YouTube/ -- файлы добавленные за вчера.

Сохрани в ~/obsidian-vault/Ideas/daily-{ДАТА}.md.

### 10. Генерация Threads по последнему YouTube
**Расписание:** по триггеру или каждый день в 10:00 → `0 7 * * *`
```
Найди последний файл в ~/obsidian-vault/YouTube/ по дате.

из ~/obsidian-vault/Threads/MOC-Threads.md.
Сохрани в ~/obsidian-vault/Threads/drafts/ДАТА.md.
Отправь варианты в Telegram.
```

### 11. Еженедельная статистика канала
**Расписание:** каждое воскресенье 20:00 МСК → `0 17 * * 0`
```

Сравни с предыдущей неделей: подписчики, охваты, лучший пост.
Отправь сводку в Telegram.
```

### 12. Архивирование черновиков

```

Отправь в Telegram: "Архивировано {N} черновиков за {месяц}."
```

## Для разработчиков и технарей

### 13. Аудит зависимостей проекта
**Расписание:** каждый понедельник → `0 3 * * 1`
```
Прочитай package.json из ~/my-project/ (или твой путь к проекту).
Найди зависимости старше 6 месяцев или с известными уязвимостями.
Отправь список в Telegram с кратким описанием что нужно обновить.
```

### 14. Дайджест незакрытых TODO
**Расписание:** каждую пятницу → `0 14 * * 5`
```
Найди все TODO и FIXME в ~/my-project/ (grep рекурсивно).
Сгруппируй по файлам. Отправь список в Telegram.
Топ-3 самых старых TODO выдели отдельно.
```

### 15. Мониторинг логов на ошибки
**Расписание:** каждый час → `0 * * * *`
```
Прочитай последние 100 строк /var/log/app.log (или твой путь).
Найди строки с ERROR, CRITICAL, Exception.
Если нашёл что-то новое с прошлой проверки — отправь в Telegram.
Если всё чисто — молчи.
```

### 16. Еженедельный бэкап конфигов
**Расписание:** каждое воскресенье 03:00 UTC → `0 3 * * 0`
```
Скопируй ~/.claude/agents/, ~/.claude/skills/, ~/claudeclaw/scripts/
в ~/obsidian-vault/ClaudeClaw/backups/{ДАТА}/.
Отправь в Telegram: "Бэкап создан: {N} файлов."
```

```

**Расписание:** каждый вечер 21:00 МСК → `0 18 * * *`

```

Удали их. Отправь в Telegram: "Очищено {N} временных файлов."
Оставь только последние логи.
```
