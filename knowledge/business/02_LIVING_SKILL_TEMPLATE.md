# Шаблон живого скилла

Скопируй в `~/.claude/skills/[название]/SKILL.md` и заполни.
Всё в квадратных скобках — заменить на своё.

---

```markdown
---
name: [название-скилла]
description: "[Одна строка: что делает скилл и когда триггерится.
  ВАЖНО: будь точным. От этой строки зависит когда агент применяет скилл.]"
---

# [Название скилла]

[Одно предложение: зачем этот скилл существует.]

## Когда применять

Триггерные фразы:
- "[конкретная фраза 1]"
- "[конкретная фраза 2]"
- "[конкретная фраза 3]"

НЕ применять когда:
- [ситуация где скилл не нужен]
- [ещё одна ситуация]

## Что делать (шаги)

1. [Первый шаг — конкретное действие]
2. [Второй шаг]
3. [Третий шаг]
4. [Проверить результат по критериям ниже]

## Критерии хорошего результата

- ✅ [Критерий 3]

Результат плохой если:
- ❌ [Антипаттерн 1]
```

## Промпт для создания скилла через агента

Отправь агенту — он создаст файл по шаблону:

```
Создай скилл для меня по следующему шаблону.

Название скилла: [название]
Что должен делать: [описание в 2-3 предложениях]
Когда триггерится: [список фраз которые запускают скилл]
Когда НЕ триггерится: [фразы которые не должны запускать]

Три примера хорошего результата:
1. [вход] → [эталонный выход]
2. [вход] → [эталонный выход]
3. [вход] → [эталонный выход]

Критерии хорошего результата:
- [критерий 1]
- [критерий 2]

Что запрещено:
- [запрет 1]
- [запрет 2]

Создай файл в ~/.claude/skills/[название]/SKILL.md
После создания — прогони Quality Gate: два промпта которые должны его запустить
и один который не должен.
```

---

## Важные правила шаблона

**Description = главная строка**
Это то что агент читает чтобы решить применять ли скилл. Слишком широко — триггерится когда не надо. Слишком узко — не триггерится когда надо.

**Примеры важнее инструкций**
Три реальных примера из твоей практики дают больше чем страница текстовых правил.

**Раздел "Запрещено" обязателен**
Агент должен знать что не делать — не только что делать.

**"Выученные паттерны" — не трогать вручную**
Этот раздел обновляет /dream на основе логов. Если редактировать руками — /dream может затереть правки.
