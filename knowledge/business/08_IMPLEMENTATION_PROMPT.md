# Master Implementation Prompt — Построй мне систему Living Skills

Отдай этот промпт своему агенту.  
Он должен не объяснять, а построить основу системы у тебя в проекте.

---

```text
Твоя задача: построить в этом проекте основу системы Living Skills.

Цель:
Превратить обычные skills из статичных markdown-файлов в систему, где skills:
- имеют критерии качества
- опираются на реальные примеры
- собирают обратную связь
- накапливают паттерны
- улучшаются контролируемо

Сделай по шагам:

1. Проведи аудит всех текущих skills
   Для каждого skill определи:
   - насколько он узкий или расплывчатый
   - есть ли критерии качества
   - есть ли реальные examples
   - есть ли feedback loop
   - есть ли механизм controlled update

2. Выбери 1 самый важный skill для пилота
   Критерии выбора:
   - часто используется
   - результат можно быстро проверить
   - улучшение даст заметную пользу

3. Построй для него living skill структуру
   Создай:
   - SKILL.md
   - criteria.md
   - examples/
   - feedback-log.jsonl
   - learned-patterns.md
   - pending-updates.md
   - rejected-patterns.md

4. Наполни skill реальным содержимым
   - уточни триггеры
   - задай чёткий output
   - добавь запрещённые паттерны
   - добавь 3 хороших примера
   - задай quality criteria

5. Добавь feedback loop
   После выполнения задачи skill должен:
   - спросить пользователя: "Результат 1-5? Что улучшить одной фразой?"
   - записать ответ в feedback-log.jsonl
   - извлекать повторяющиеся паттерны
   - складывать подтверждённые сигналы в learned-patterns.md
   - не менять ядро skill сразу

6. Добавь controlled update rule
   Правило:
   - если паттерн повторился 3+ раза, создай запись в pending-updates.md
   - только после этого предлагай обновление ядра skill

7. Проведи тесты
   Нужны:
   - один слабый результат "до"
   - один улучшенный результат "после"
   - один цикл feedback loop

8. Верни итог
   В ответе покажи:
   - какой skill выбран пилотом
   - какие файлы созданы
   - где была главная проблема
   - что именно улучшилось
   - что делать следующим шагом

Важно:
- не делай теорию ради теории
- не создавай лишние файлы без пользы
- не переписывай все skills сразу
- сначала один пилотный skill, но сделанный хорошо
```

## Как понять, что система реально заработала

После внедрения должно быть видно:
- результат стал стабильнее
- правки стали повторяться реже
- skill использует реальные примеры
- в `learned-patterns.md` появились рабочие сигналы
- у skill есть управляемый путь улучшения
