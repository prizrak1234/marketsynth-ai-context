# Codex с нуля — полная инструкция по сборке ИИ-сотрудника на Codex CLI

> Формат: пошаговое видео. Каждый шаг = раздаточный файл-промпт, который зритель кидает Codex и тот сам выполняет.
> Раздаточные: `Раздаточные материалы для видео/codex-setup/`

---

## Введение (2-3 мин)

- Codex CLI от OpenAI стал реально рабочим инструментом
- Это не замена Claude Code, это второй ИИ-сотрудник в твоей команде
- Сегодня соберём его с нуля до полноценного ИИ-сотрудника с памятью, скиллами и управлением через Telegram
- Формат: на каждом шаге даю готовый файл-промпт. Кидаешь его Codex — он сам всё делает за пару минут
- Все файлы в первом закреплённом сообщении

## Готовые промпты для Codex по шагам

Используй их как готовый copy-paste в Codex, начиная со `STEP-02`.

Workflow:
- Trigger: ты переходишь к следующему шагу в видео
- Inputs: текущая директория проекта + нужный `STEP-*.md` файл в `/root/CodexClaw/`
- Outputs: Codex читает файл, выполняет шаг, просит недостающие данные и проверяет результат
- Risk level: низкий, если запускать шаги по порядку

## Шаг 1 — Установка Codex на VDS (3-4 мин)

**Зачем:** получить рабочий Codex CLI на сервере, чтобы он работал 24/7.

**Что делаем:**
- Покупаем VDS (USA локация, ~$6/мес, рекомендации по хостингу)
- Подключаемся через SSH (Termius / VS Code)
- Обновляем сервер, ставим Node.js 22
- Устанавливаем Codex CLI
- Авторизуемся через device code
- Инициализируем проект: `codex /init` создаёт AGENTS.md
- Проверяем: `codex exec "echo test"`

**Команды:**
```bash
apt update && apt upgrade -y
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs
npm install -g @openai/codex pm2
codex login
mkdir -p ~/CodexClaw && cd ~/CodexClaw && codex /init
```

**Раздаточный файл:** `STEP-01_INSTALL.md`

## Шаг 2 — Подключение моста к Telegram (5-6 мин)

**Зачем:** управлять Codex через Telegram, а не через терминал. Отправлять задачи с телефона.

**Что делаем:**
- Создаём бота через @BotFather
- Получаем chat_id через @userinfobot
- Кидаем промпт-файл в Codex — он сам создаёт проект: grammy + TypeScript + persistent sessions
- Архитектура: каждый чат получает свою сессию Codex, которая сохраняется между сообщениями
- Запускаем через pm2
- Проверяем: пишем боту в Telegram

**Раздаточный файл:** `STEP-02_TELEGRAM_BRIDGE.md`

---

## Шаг 3 — Красивые ответы и работа с медиа (4-5 мин)

**Зачем:** бот должен отвечать читаемо (Telegram HTML-разметка), принимать голосовые, фото, видео-кружочки и файлы.

**Что делаем:**
- Добавляем Telegram HTML форматирование с безопасным разбиением (не рвёт теги)
- Подключаем приём голосовых → Whisper API (openai ^6.0.0) для транскрибации
- Приём фото и видео-кружочков с описанием
- Приём файлов (PDF, DOCX, изображения) — сохранение в workspace/inbox/
- Отправка файлов обратно пользователю по запросу

**Раздаточный файл:** `STEP-03_MEDIA_AND_FORMATTING.md`

## Шаг 4 — Память: три уровня (5-6 мин)

**Зачем:** без памяти агент забывает всё после каждой сессии. С памятью он знает кто ты, что делал вчера и какие у тебя проекты.

**Что делаем:**
- **Уровень 1 — Оперативная память (AGENTS.md):** стандартный проектный файл Codex — кто ты, как отвечать, правила
- **Уровень 2 — Долгосрочная память (agent-memory.md):** факты, решения, наблюдения, которые агент записывает сам после сессий
- **Уровень 3 — Внешняя база (Obsidian):** заметки, граф знаний, документы. Агент ищет в vault по запросу, не загружает всё в контекст

**Структура файлов:**
```
~/CodexClaw/
  AGENTS.md            ← уровень 1 (оперативная)
  agent-memory.md       ← уровень 2 (долгосрочная)
  ~/obsidian-vault/     ← уровень 3 (внешняя)
```

**Раздаточный файл:** `STEP-04_MEMORY.md`

## Шаг 5 — Скиллы: готовые и свои (4-5 мин)

**Зачем:** скиллы — это готовые инструкции для повторяемых задач. Вместо объяснения каждый раз, агент сам знает как делать.

**Что делаем:**
- Устанавливаем скиллы из официального каталога OpenAI (github.com/openai/skills):
  - `imagegen` — генерация картинок
  - `doc` — создание документов
  - `slides` — презентации
- Ставим через `$skill-installer` прямо внутри Codex
- Создаём свой первый скилл (например: парсинг YouTube видео)
- Структура скилла: SKILL.md + scripts/ + reference/
- Сторонние каталоги: skills.sh (Vercel), SkillsMP.com
- Важно: формат скиллов теперь кросс-платформенный (работает и в Claude Code, и в Codex)

**Раздаточный файл:** `STEP-05_SKILLS.md`

## Шаг 6 — Команды управления (3-4 мин)

**Зачем:** управлять агентом как сотрудником — давать команды для сохранения прогресса, очистки контекста, консолидации знаний.

**Что делаем:**
- `/newchat` — сохранить прогресс + начать чистую сессию
- `/checkpoint` — сохранить итоги текущей работы в память
- `/dream` — консолидация памяти: агент перечитывает agent-memory.md, удаляет устаревшее, обобщает
- `/compact` — показать сводку контекста + предложить /clear
- `/clear` — очистить сессию для новой задачи (бот сбрасывает session_id)
- `/status` — отчёт о текущем состоянии
- Автоматическое напоминание при смене темы: "Новая тема — лучше /clear"

**Раздаточный файл:** `STEP-06_COMMANDS.md`

## Шаг 7 — Подключение инструментов (4-5 мин)

**Зачем:** агент без инструментов — это просто чат. С инструментами он работает с файлами, ищет в интернете, управляет сервисами.

**Что делаем:**
- **Веб-поиск:** встроенный в Codex (работает из коробки)
- **Google Workspace:** gws CLI (если установлен и настроен)
- **n8n:** вебхуки для автоматизации линейных задач (curl → webhook → результат)
- **Веб-скрапинг:** curl + w3m для простых страниц, Firecrawl API для JS-тяжёлых сайтов
- **GitHub:** gh CLI для работы с репозиториями и PR
- Показать пример: агент получает задачу → дёргает webhook n8n → получает результат → отвечает в Telegram

**Раздаточный файл:** `STEP-07_TOOLS.md`

---

## Шаг 8 — Перекрёстная проверка: самоаудит + Claude (3-4 мин)

**Зачем:** один агент не видит своих ошибок. Нужна система проверки.

**Что делаем:**
- Протокол самопроверки после сложных задач (5+ шагов)
- Команда `/audit` — полная проверка работоспособности всех систем
- Claude Code как внешний рецензент (если установлен на том же сервере)
- Показываем реальный пример: Codex выполнил задачу → Claude нашёл ошибку → исправили

**Раздаточный файл:** `STEP-08_SUPERVISOR.md`
