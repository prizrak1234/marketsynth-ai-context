# /dream — еженедельная автоэволюция скиллов

## Что делает /dream

Раз в неделю собирает всё что агент узнал за 7 дней — ошибки, паттерны, фидбек — и обновляет файлы скиллов. Без твоего участия. Скиллы становятся умнее пока ты спишь.

Это Level 4. Самое важное в системе Living Skills.

---

## Вариант 1: Добавить команду dream в CLAUDE.md (простой способ)

Добавь в свой `CLAUDE.md` или `SYSTEM_PROMPT.md`:

```markdown
### /dream или dream

Триггер: пользователь пишет "dream", "/dream" или "обнови скиллы".

Что делать:
1. Прочитай все файлы feedback.log из ~/.claude/skills/*/feedback.log
2. Для каждого скилла — проанализируй записи с оценкой ≤ 3
3. Найди повторяющиеся паттерны ошибок (3+ раза = устойчивый паттерн)
4. Для каждого паттерна — добавь правило в раздел "Выученные паттерны"
   соответствующего SKILL.md
5. Прочитай agent-memory.md (если есть) — извлеки паттерны из сессий
6. Обнови CLAUDE.md раздел "Learned Patterns" — добавь новые обобщения
7. Отчитайся: сколько скиллов обновлено, какие правила добавлены

Не удалять существующие правила. Только добавлять и уточнять.
```

## Вариант 2: Создать отдельный skill для /dream

Создай файл `~/.claude/skills/dream/SKILL.md`:

```markdown
---
name: dream
description: Weekly skill evolution. Analyze all feedback.log files, extract patterns, update skill files. Trigger: "dream", "/dream", "обнови скиллы", "консолидируй".
---

# Dream — Skill Evolution

## Что делаю

Анализирую накопленный фидбек и обновляю все скиллы.

## Шаги

1. Найди все feedback.log в ~/.claude/skills/*/feedback.log
2. Для каждого файла:
   a) Прочитай все записи с оценкой ≤ 3
   b) Найди паттерны (3+ похожих жалобы = устойчивый паттерн)
   c) Сформулируй правило из паттерна
   d) Добавь в раздел "Выученные паттерны" этого SKILL.md
3. Прочитай agent-memory.md или Sessions/ — извлеки поведенческие паттерны
4. Обнови Learned Patterns в CLAUDE.md
5. Отчитайся

## Формат отчёта

---
/dream завершён — [дата]

Обработано скиллов: [N]
Добавлено правил: [N]

Изменения:
• [скилл]: добавлено правило "[текст правила]"
• [скилл]: добавлено правило "[текст правила]"

Следующий /dream: через 7 дней
---
```

## Вариант 3: Автоматический запуск по расписанию

Если у тебя настроен Claude по расписанию — добавь dream в cron:

```bash
# Запускать /dream каждое воскресенье в 23:00
0 23 * * 0 claude -p "dream — проведи еженедельную консолидацию скиллов" >> ~/logs/dream.log 2>&1
```

Или через scheduler ClaudeClaw:
```
node /root/claudeclaw/dist/schedule-cli.js create "dream — обнови все скиллы на основе накопленного фидбека" "0 23 * * 0" [CHAT_ID]
```

## Промпт для первого запуска /dream вручную

```
Запусти dream — первую консолидацию скиллов.

Сделай следующее:
1. Найди все файлы в ~/.claude/skills/ — прочитай каждый SKILL.md
2. Для каждого скилла проверь:
   - Есть ли feedback.log? Если есть — проанализируй
   - Есть ли раздел "Выученные паттерны"? Если нет — создай пустой
3. Если feedback.log есть и содержит записи с оценкой ≤ 3:
   - Найди повторяющиеся проблемы
   - Сформулируй 1-2 новых правила
   - Добавь в "Выученные паттерны"
4. Покажи отчёт: что нашёл, что добавил, что оставил без изменений
```
