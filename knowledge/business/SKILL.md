# Premium Web Development

This skill provides a set of professional rules and workflows to ensure high-quality web development.

## Rules
- [00-basics.md](rules/00-basics.md): Typography, aesthetics, and avoiding "AI slop".
- [01-architecture.md](rules/01-architecture.md): Core HTML/CSS architecture and tech stack constraints.
- [02-module-generation.md](rules/02-module-generation.md): Workflow for converting references to code and ensuring modularity.
- [03-content-guidelines.md](rules/03-content-guidelines.md): Copywriting rules for human-sounding text.
- [04-animation.md](rules/04-animation.md): Micro-interactions and motion guidelines.

## Implementation Templates
- [golden-layout.html](templates/golden-layout.html): Optimized HTML5 boilerplate.
- [premium-reset.css](templates/premium-reset.css): Modern CSS variables & reset.

## Workflows
- [Rapid Site Build](workflows/rapid_site_build.md): The "Master Prompt" for instant project setup.

## Usage
When asked to build a website or component, strictly adhere to these rules.
1. **Basics**: Always check `00-basics.md` for font choices and aesthetic guidelines.
2. **Architecture**: Follow `01-architecture.md` for the user's specific project setup.
3. **Modules**: Use `02-module-generation.md` when adding new sections or components.
4. **Rapid Build**: Use the `workflows/rapid_site_build.md` workflow for new projects to save time.
