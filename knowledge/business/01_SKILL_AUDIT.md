# Аудит скиллов — найди мёртвый груз

## Что делает этот промпт

Твой агент пройдётся по всем существующим скиллам и выдаст:
- Какие скиллы живые и работают
- Какие мёртвые (нет примеров, нет критериев, не триггерятся)
- Что удалить прямо сейчас
- Что починить в первую очередь

---

## Промпт для аудита (скопируй и отправь агенту)

```
Проведи аудит всех моих скиллов. Вот что нужно сделать:

1. Найди папку со скиллами (у Claude Code: ~/.claude/skills/)
2. Для каждого скилла проверь:
   a) Есть ли внутри раздел с реальными примерами (не просто инструкции)?
   b) Есть ли конкретные критерии хорошего результата (длина, формат, запреты)?
   c) Есть ли секция "feedback" или "memory" для фиксации ошибок?
   d) Триггер точный или слишком широкий (может срабатывать когда не надо)?

3. Классифицируй каждый скилл:
   🔴 МЁРТВЫЙ — нет примеров + нет критериев. На удаление или переработку.
   🟡 СЛАБЫЙ — есть что-то одно. Требует доработки.
   🟢 ЖИВОЙ — есть примеры + критерии. Работает стабильно.

4. Выдай результат в таком формате:

---
АУДИТ СКИЛЛОВ — [дата]

🔴 МЁРТВЫЕ (удалить или переделать):
- [название]: [причина]

🟡 СЛАБЫЕ (доработать):
- [название]: [что добавить]

🟢 ЖИВЫЕ (оставить как есть):
- [название]: [что делает хорошо]

ИТОГО: [N] скиллов. Мёртвых: [N]. Освободить токенов: примерно [N] строк контекста.

ПЕРВЫЙ ШАГ: возьми [название скилла] и добавь раздел с 3 примерами.
---
```

---

## Правило 60 дней

Скилл, который не триггерился 60 дней = на ревизию.

Три вопроса для каждого скилла:
1. Когда последний раз использовался?
2. Триггер точный или слишком широкий?
3. Нужен ли этот скилл в текущем воркфлоу?

Если ответ "не знаю" на все три — удаляй.

---

## Что делать с мёртвыми скиллами

**Вариант 1: Удалить**
```bash
rm -rf ~/.claude/skills/[название]/
```

**Вариант 2: Переработать**
Открой `02_LIVING_SKILL_TEMPLATE.md` и замени содержимое.

**Вариант 3: Объединить**
Если два похожих скилла — объедини в один с более точным триггером.

---

## Промпт для удаления мёртвых скиллов

```
Посмотри на результаты аудита. Удали все скиллы которые помечены как 🔴 МЁРТВЫЕ.
Перед удалением — покажи мне список что будет удалено и подожди подтверждения.
После удаления — снова выведи список оставшихся скиллов и посчитай сколько строк
контекста освободилось.
```
