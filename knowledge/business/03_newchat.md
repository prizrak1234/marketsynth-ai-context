# Команда: /newchat

## Что делает

Завершает текущую сессию, сохраняет checkpoint и сигналит начать новый чат. Контекстное окно сбрасывается до нуля, но вся память (SQLite, Obsidian, файлы) сохраняется и подгружается в новую сессию автоматически.

## Когда использовать

- После 3-4 compactions (качество ответов деградирует)
- При явной смене темы (перешёл от кода к контенту)
- Когда `/convolife` показывает 80%+ использования контекста
- В конце рабочего блока перед перерывом

## Как внедрить в своего агента

### Вариант 1 — Через CLAUDE.md

Добавь в `CLAUDE.md`:

```markdown
### newchat
Триггер: пользователь пишет "newchat", "/newchat" или "новый чат".

Действия:
1. Выполни checkpoint (сохрани 3-5 итогов сессии в SQLite + Obsidian)
2. Сообщи: "Готово. Начни новую сессию — контекст сохранён."

Что сохраняется между сессиями:
- Memories из SQLite (инжектятся в новый промпт автоматически)
- Заметки в Obsidian
- Все файлы в workspace/
```

### Вариант 2 — Через Skill

Создай `~/.claude/skills/newchat/SKILL.md`:

```markdown
---
name: newchat
description: Save current session checkpoint then signal user to start a new chat session. Trigger when user says "newchat", "/newchat", or "новый чат".
---

# Newchat — Start Fresh Session

## Instructions

1. Run checkpoint (save 3-5 bullet summary to memories table)
2. Tell user: "Готово. Начни новую сессию — контекст сохранён."

What persists into new session:
- Memories from SQLite (injected into new prompt)
- Obsidian notes
- All files in workspace/
```

### Промпт для внедрения (скопируй и отправь агенту)

```
Внедри команду /newchat в мою систему. Вот инструкция:

Когда я пишу "newchat", "/newchat" или "новый чат":
1. Сначала сделай checkpoint — сохрани 3-5 ключевых итогов сессии
2. Затем скажи: "Готово. Начни новую сессию — контекст сохранён."

Важно: память из SQLite/Obsidian/файлов подгружается в новую сессию автоматически.
Команда нужна, чтобы сбросить контекстное окно (оно конечное — 200k токенов),
сохранив при этом все важные решения и факты.

Создай skill файл для этого в ~/.claude/skills/newchat/SKILL.md
```

## Примеры использования

**Пример 1 — после долгой сессии:**
```
Пользователь: newchat

Агент: Checkpoint сохранён. Готово. Начни новую сессию — контекст сохранён.
• Настроен парсер Instagram Reels
• Добавлен новый формат экспорта в CSV
• Исправлен таймаут при обработке длинных видео
```

**Пример 2 — смена темы:**
```
Пользователь: Всё, с кодом закончили. Давай новый чат, дальше контент.

Агент: Checkpoint сохранён. Начни новую сессию — контекст сохранён.
• Рефакторинг scheduler.ts завершён
• Добавлены проверки для /schedule create и /schedule delete
• Баг с timezone в schedule исправлен
```

**Пример 3 — после 3 compactions:**
```
Пользователь: /convolife
Агент: Context: 87% used — ~26k tokens remaining

Пользователь: /newchat
Агент: Checkpoint сохранён. Начни новую сессию — контекст сохранён.
```

## Связанные команды

- `/checkpoint` — newchat автоматически вызывает checkpoint перед сбросом
- `/convolife` — проверь загрузку контекста, чтобы понять нужен ли newchat
- `/compact` — альтернатива: сжать контекст без полного сброса (если задача не закончена)
