## 🔴 ЧТО БЫЛО СЛОМАНО

### Проблема 1: Router возвращал undefined
**Причина**: Использовалось выражение `{{ $json.message.text.split(' ')[0].substring(1) }}`, которое не работает для сложных команд.

**Исправление**: Создана нода **Extract Command** с JavaScript-кодом, который правильно извлекает команду и параметры.

### Проблема 2: Нижняя ветка (HTTP Request) не выполнялась
**Причина**: IF-нода проверяла неправильное условие `isStart` вместо `isStartCommand`.

**Исправление**: IF-нода теперь проверяет `isStartCommand` (boolean), который устанавливается в коде Extract Command.

### НОДА 2: Extract Command (Code)
**Тип**: `Code`

**JavaScript Code**:
```javascript
// Извлекаем текст сообщения
const message = $input.item.json.message;
const text = message?.text || '';

// Определяем команду и webhook
let command = '';
let webhookPath = '';
let isStartCommand = false;

if (text.startsWith('/start')) {
    command = 'start';
    isStartCommand = true;
} else if (text.startsWith('/research')) {
    command = 'research';
    webhookPath = 'research';
} else if (text.startsWith('/content')) {
    command = 'content';
    webhookPath = 'content';
} else if (text.startsWith('/seo')) {
    command = 'seo';
    webhookPath = 'seo';
} else if (text.startsWith('/webdev')) {
    command = 'webdev';
    webhookPath = 'webdev';
} else if (text.startsWith('/strategy')) {
    command = 'strategy';
    webhookPath = 'strategy';
} else {
    command = 'unknown';
}

// Извлекаем запрос (текст после команды)
const query = text.replace(/^\/\w+\s*/, '').trim();

return {
    command: command,
    webhookPath: webhookPath,
    isStartCommand: isStartCommand,
    query: query,
    chatId: message.chat.id,
    originalMessage: text
};
```

**Подключение**: Telegram Trigger → Extract Command

### НОДА 6: Extract Response (Code)
**Тип**: `Code`

**JavaScript Code**:
```javascript
const response = $input.item.json;
const chatId = $input.first().json.chatId;
const command = $input.first().json.command;

// Извлекаем summary из ответа модуля
let summary = 'Ошибка получения ответа';

if (response && response.summary) {
    summary = response.summary;
} else if (response && response.result) {
    summary = response.result;
} else if (typeof response === 'string') {
    summary = response;
}

return {
    chatId: chatId,
    module: command.toUpperCase(),
    summary: summary
};
```

**Подключение**: Call Module → Extract Response

## 🚨 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проблема: Бот не отвечает
**Решение**: 
1. Проверьте, что бот **активирован** (Active = ON)
2. Проверьте, что **все 3 ноды Telegram** настроены с правильным токеном
3. Проверьте логи выполнения: **Executions** → последний запуск

### Проблема: Возвращается undefined
**Решение**: 
1. Откройте ноду **Extract Command**
2. Убедитесь, что код скопирован **полностью**
3. Протестируйте ноду: выполните workflow с тестовым сообщением `/research test`

### Проблема: HTTP Request не работает
**Решение**:
1. Откройте модуль (например, Research Module) в отдельной вкладке
2. Убедитесь, что он **активен** (Active = ON)
3. Скопируйте **Production URL** из Webhook-ноды
4. Вставьте в ноду Call Module бота

### Проблема: Модули возвращают 404
**Решение**:
Активируйте все модули вручную:
1. Откройте https://sarbastn8n.ru/workflows
2. Для каждого модуля (Research, Content, SEO, WebDev, Strategy):
   - Откройте workflow
   - Active = ON
   - Save
