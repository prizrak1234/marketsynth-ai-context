# Шаг 5: Библиотека ассетов и реестр лиц, шаблонов и стилей

Твоя система должна уметь работать не только с нуля, но и с постоянными заготовками.

## Зачем нужен registry

Чтобы агент:
- знал, какое лицо использовать для YouTube-обложек
- знал, какой шаблон подходит для конкретного формата
- держал единый визуальный стиль
- не спрашивал одни и те же вещи каждый раз

## Базовая структура

```text
workspace/library/image-assets/
  registry.json
  faces/
  templates/
  styles/
  refs/
```

## Какие сущности хранить

### Лица

- основной портрет автора
- альтернативные ракурсы
- дополнительные участники или ведущие

### Шаблоны

- YouTube thumbnail clean
- YouTube thumbnail bold
- Instagram quote card
- ad creative layout

### Стили

- neon tech
- clean business
- premium dark

### Референсы

- композиции
- фоны
- сцены
- продуктовые примеры

## Правило выбора

Когда приходит задача вроде:

```text
Сделай обложку для YouTube про ИИ-агентов
```

система должна:
1. понять тип задачи: `youtube-thumbnail`
2. открыть `registry.json`
3. подобрать подходящее лицо
4. подобрать шаблон
5. подобрать стиль
6. на этой базе собрать итоговый prompt

## Важно

Registry не должен быть просто свалкой файлов.

Для каждого объекта нужны:
- `id`
- `type`
- `label`
- `path`
- `use_for`
- `tags`
- `priority`
