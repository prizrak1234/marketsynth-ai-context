# Шаг 2 — Создаём первые задачи

## Формат команды

```bash
node dist/schedule-cli.js create "ПРОМПТ" "CRON" CHAT_ID
```

- `ПРОМПТ` — что должен сделать агент (в кавычках)
- `CRON` — расписание (в кавычках)
- `CHAT_ID` — ваш Telegram chat ID (без кавычек)

Как узнать свой CHAT_ID: напишите боту `@userinfobot` в Telegram.

---

## Готовые задачи — копируйте и вставляйте

### Утренний дайджест (каждый день в 9:00)

```bash
node dist/schedule-cli.js create \
  "Сделай краткий утренний дайджест: 1) проверь папку workspace/inbox/ на новые файлы, 2) напомни что было сделано вчера из session notes если есть, 3) погода на сегодня через веб-поиск. Уложи в 5-7 строк. Если нечего сообщать — напиши только погоду." \
  "0 9 * * *" \
  ВАШ_CHAT_ID
```

### Еженедельный дайджест (каждое воскресенье в 10:00)

```bash
node dist/schedule-cli.js create \
  "Сделай weekly digest: просмотри заметки в obsidian-vault/YouTube/ за последние 7 дней, выдели 3-5 главных инсайтов которые стоит внедрить. Формат: bullet-список, кратко." \
  "0 10 * * 0" \
  ВАШ_CHAT_ID
```

### Мониторинг ошибок (каждые 4 часа по будням)

```bash
node dist/schedule-cli.js create \
  "Проверь логи ошибок: запусти node /root/claudeclaw/scripts/eval.js stats и если есть ошибки типа webhook_error или timeout за последние 24 часа — сообщи. Если всё чисто — промолчи." \
  "0 9,13,17 * * 1-5" \
  ВАШ_CHAT_ID
```

### Напоминание о checkpoint по пятницам (17:00)

```bash
node dist/schedule-cli.js create \
  "Напомни: пятница, время сохранить итоги недели. Напиши 2-3 строки — что было сделано за неделю на основе session notes в obsidian-vault/Sessions/. Предложи написать /checkpoint." \
  "0 17 * * 5" \
  ВАШ_CHAT_ID
```

### Контент-идея раз в неделю (понедельник 10:00)

```bash
node dist/schedule-cli.js create \
  "Предложи 3 идеи для контента на эту неделю на основе YouTube-заметок в obsidian-vault/YouTube/ за последние 14 дней. Формат: название идеи + 1 строка почему актуально." \
  "0 10 * * 1" \
  ВАШ_CHAT_ID
```

## Проверяем результат

```bash
node dist/schedule-cli.js list
```

Должны видеть все добавленные задачи со статусом `active` и датой следующего запуска.
