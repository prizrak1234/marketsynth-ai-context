# Living Skills — Раздаточные материалы

**К видео:** "Почему 99% AI-скиллов — мёртвый груз и как это исправить"

Всё что нужно, чтобы превратить свои мёртвые скиллы в живые.
Отдай эти файлы своему агенту — он построит систему за тебя.

---

## Что внутри

| Файл | Что там |
|------|---------|
| `01_SKILL_AUDIT.md` | Промпт для аудита всех существующих скиллов |
| `02_LIVING_SKILL_TEMPLATE.md` | Шаблон живого скилла — копировать и заполнять |
| `03_GOLD_EXAMPLES_GUIDE.md` | Как создать золотой датасет примеров |
| `04_FEEDBACK_LOOP.md` | Петля обратной связи — скилл который учится сам |
| `05_DREAM_SETUP.md` | Как настроить еженедельную автоэволюцию |
| `06_QUALITY_GATE.md` | 3 теста перед запуском любого скилла |
| `07_DEMO_PROMPTS.md` | Точные промпты для всех демонстраций из видео |
| `08_IMPLEMENTATION_PROMPT.md` | Главный промпт: построй мне систему Living Skills |

---

## Четыре уровня скилла

```
Уровень 1 [МЁРТВЫЙ]   — текст без примеров         → агент угадывает
Уровень 2 [РАБОЧИЙ]   — текст + золотые примеры     → агент попадает в стиль
Уровень 3 [УМНЫЙ]     — + память ошибок             → агент помнит провалы
Уровень 4 [ЖИВОЙ]     — + автообновление (/dream)   → агент учится сам
```

---

## Минимальный старт (10 минут)

1. Открой `01_SKILL_AUDIT.md` — скопируй промпт и отправь своему агенту
2. Получи список: какие скиллы живые, какие мёртвые
3. Возьми один важный скилл и применить к нему `02_LIVING_SKILL_TEMPLATE.md`
4. Добавь 3 примера по инструкции из `03_GOLD_EXAMPLES_GUIDE.md`
5. Прогони `06_QUALITY_GATE.md` — три теста

Этого достаточно чтобы увидеть разницу в первый же день.

## Требования

- 10 минут на первый аудит
