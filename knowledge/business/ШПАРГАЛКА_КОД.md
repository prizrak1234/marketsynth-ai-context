## НОДА 2: Extract Command (CODE)

**Скопируйте этот код полностью**:

```javascript
// Извлекаем текст сообщения
const message = $input.item.json.message;
const text = message?.text || '';

// Определяем команду и webhook
let command = '';
let webhookPath = '';
let isStartCommand = false;

if (text.startsWith('/start')) {
    command = 'start';
    isStartCommand = true;
} else if (text.startsWith('/research')) {
    command = 'research';
    webhookPath = 'research';
} else if (text.startsWith('/content')) {
    command = 'content';
    webhookPath = 'content';
} else if (text.startsWith('/seo')) {
    command = 'seo';
    webhookPath = 'seo';
} else if (text.startsWith('/webdev')) {
    command = 'webdev';
    webhookPath = 'webdev';
} else if (text.startsWith('/strategy')) {
    command = 'strategy';
    webhookPath = 'strategy';
} else {
    command = 'unknown';
}

// Извлекаем запрос (текст после команды)
const query = text.replace(/^\/\w+\s*/, '').trim();

return {
    command: command,
    webhookPath: webhookPath,
    isStartCommand: isStartCommand,
    query: query,
    chatId: message.chat.id,
    originalMessage: text
};
```

## НОДА 6: Extract Response (CODE)

**Скопируйте этот код полностью**:

```javascript
const response = $input.item.json;
const chatId = $input.first().json.chatId;
const command = $input.first().json.command;

// Извлекаем summary из ответа модуля
let summary = 'Ошибка получения ответа';

if (response && response.summary) {
    summary = response.summary;
} else if (response && response.result) {
    summary = response.result;
} else if (typeof response === 'string') {
    summary = response;
}

return {
    chatId: chatId,
    module: command.toUpperCase(),
    summary: summary
};
```

## 🔗 ПОДКЛЮЧЕНИЕ НОД (CONNECTIONS)

```
Telegram Trigger → Extract Command → Check Command
                                            ↓
                                    ┌───────┴───────┐
                                    ↓               ↓
                            Send Start Message   Call Module
                                                    ↓
                                            Extract Response
                                                    ↓
                                               Send Result
```

**В n8n**:
1. Telegram Trigger → перетащите выход на Extract Command
2. Extract Command → перетащите выход на Check Command
3. Check Command (TRUE выход, зелёная линия) → Send Start Message
4. Check Command (FALSE выход, красная линия) → Call Module
5. Call Module → Extract Response
6. Extract Response → Send Result

## 🚨 ЕСЛИ НЕ РАБОТАЕТ

### Бот не отвечает вообще
1. Проверьте Active = ON
2. Проверьте Telegram credentials во всех 3 нодах
3. Проверьте Executions → последний лог

### Возвращается undefined
1. Проверьте код Extract Command (скопирован полностью?)
2. Проверьте IF-ноду: `{{ $json.isStartCommand }}` == `true`

### HTTP Request не работает
1. Убедитесь, что модули активны: https://sarbastn8n.ru/workflows
2. Проверьте URL в Call Module: `https://sarbastn8n.ru/webhook/{{ $json.webhookPath }}`
3. Протестируйте модуль напрямую:
```bash
curl -X POST https://sarbastn8n.ru/webhook/research \
  -H "Content-Type: application/json" \
  -d '{"query": "тест"}'
```
