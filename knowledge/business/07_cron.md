# Команда: /schedule (create, list, pause, resume, delete)

## Что делает

Планировщик задач по расписанию. В CodexClaw отдельного семейства `CronCreate / CronList / CronDelete` нет. Вместо него используется одна команда `/schedule` с подкомандами создания, просмотра, паузы, возобновления и удаления задач.

Команды:

- **`/schedule create <cron> <prompt>`** — создать задачу
- **`/schedule list`** — посмотреть активные задачи
- **`/schedule pause <taskId>`** — поставить на паузу
- **`/schedule resume <taskId>`** — возобновить
- **`/schedule delete <taskId>`** — удалить задачу

## Когда использовать

- Ежедневный утренний брифинг
- Еженедельный дайджест по видео и трендам
- Напоминания о дедлайнах и встречах
- Мониторинг сайта, конкурентов и упоминаний
- Автоматический `/dream` по расписанию

## Синтаксис cron-выражений

```text
┌───────── минуты (0-59)
│ ┌───────── часы (0-23)
│ │ ┌───────── день месяца (1-31)
│ │ │ ┌───────── месяц (1-12)
│ │ │ │ ┌───────── день недели (0-7, 0 и 7 = воскресенье)
│ │ │ │ │
* * * * *
```

Частые паттерны:

| Расписание | Cron | Пример |
|-----------|------|--------|
| Каждый день в 9:00 | `0 9 * * *` | Утренний брифинг |
| Каждый понедельник в 10:00 | `0 10 * * 1` | Еженедельный дайджест |
| Каждые 6 часов | `0 */6 * * *` | Мониторинг |
| 1 и 15 числа в 9:00 | `0 9 1,15 * *` | Напоминание об оплате |
| Пятница в 18:00 | `0 18 * * 5` | Итоги недели |

## Как внедрить в своего агента

### Через CLAUDE.md

Добавь в `CLAUDE.md`:

```markdown
### Планировщик задач (/schedule)

Агент поддерживает задачи по расписанию через встроенный планировщик.

Команды:
- Создать: /schedule create 0 9 * * * проверь Gmail и отправь дайджест
- Список: /schedule list
- Пауза: /schedule pause <taskId>
- Возобновить: /schedule resume <taskId>
- Удалить: /schedule delete <taskId>
```

### Вариант 2 — CLI для сервера

Для ручной работы на сервере есть `npm run schedule` или `tsx src/schedule-cli.ts`.

### Промпт для внедрения

```text
Приведи задачи по расписанию к формату CodexClaw через /schedule.

Мне нужны команды:
1. /schedule create <cron> <prompt>
2. /schedule list
3. /schedule pause <taskId>
4. /schedule resume <taskId>
5. /schedule delete <taskId>

Важно: не придумывай отдельные CronCreate/CronList/CronDelete, если в проекте уже есть /schedule.
```

## Примеры использования

**Пример 1 — утренний брифинг:**

```text
Пользователь: /schedule create 0 9 * * * проверь Gmail, Calendar и отправь мне дайджест на сегодня

Агент: Scheduled task created: task_001
Risk: review
Policy: default
```

**Пример 2 — еженедельный dream:**

```text
Пользователь: /schedule create 0 3 * * 0 запусти /dream

Агент: Scheduled task created: task_002
Risk: safe
Policy: default
```

**Пример 3 — просмотр и удаление:**

```text
Пользователь: /schedule list

Агент: Активные задачи:
#001 | active | review | 0 9 * * * | 2026-04-21T09:00:00.000Z
#002 | active | safe | 0 3 * * 0 | 2026-04-26T03:00:00.000Z

Пользователь: /schedule delete task_002
Агент: Scheduled task deleted: task_002
```

## Связанные команды

- `/schedule templates` — покажет шаблоны готовых workflow
- `/dream` — часто ставят на cron
- `/checkpoint` — сохрани настройки планировщика перед `newchat`
