# Петля фидбека — скилл который учится после каждой задачи

## Что это даёт

Обычный скилл: ты говоришь "не так" → агент правит прямо сейчас → следующая сессия — снова то же самое.

Скилл с петлёй фидбека: ты говоришь "не так" → агент записывает → анализирует паттерн → обновляет свой файл → следующий запуск уже умнее.

Ты ставишь оценку как в Яндекс.Такси. Скилл сам разбирается что улучшить.

---

## Блок для добавления в любой SKILL.md

Скопируй и добавь в конец своего скилла:

```markdown
## Петля обратной связи

После выполнения каждой задачи:

1. Спроси пользователя: "Результат 1-5? Что улучшить одной фразой?"

2. Запиши ответ в файл ~/.claude/skills/[название]/feedback.log:
   Формат: [ДАТА] | ОЦЕНКА: [1-5] | ЗАДАЧА: [тип] | ФИДБЕК: [текст]

3. Если оценка ≤ 3 ИЛИ есть конкретный комментарий:
   a) Прочитай последние 5 записей из feedback.log
   b) Найди паттерн — что повторяется?
   c) Добавь одно новое правило в раздел "## Выученные паттерны" этого файла
   d) Формат правила: "• [что делать / не делать] — выявлено [дата]"

4. Если оценка 4-5 и нет комментария:
   → Только запись в лог. Файл скилла не менять.

## Выученные паттерны

*(Автообновление — не редактировать вручную)*
```

## Промпт для внедрения петли в существующий скилл

```
Добавь петлю обратной связи в скилл [название].

После каждой выполненной задачи скилл должен:
1. Спросить меня: "Результат 1-5? Что улучшить?"
2. Записать ответ в ~/.claude/skills/[название]/feedback.log
   в формате: [ДАТА] | ОЦЕНКА: [1-5] | ЗАДАЧА: [тип] | ФИДБЕК: [текст]
3. Если оценка ≤ 3 или есть конкретный комментарий:
   - Прочитать последние 5 записей из лога
   - Найти повторяющийся паттерн
   - Добавить одно правило в раздел "Выученные паттерны" файла скилла
4. Если оценка 4-5 и без комментариев — только запись в лог

Добавь этот блок в конец файла ~/.claude/skills/[название]/SKILL.md
Создай пустой файл ~/.claude/skills/[название]/feedback.log
```

## Пример реального feedback.log через неделю

```
2026-04-22 | ОЦЕНКА: 3 | ЗАДАЧА: хук-пост | ФИДБЕК: слишком общий, нет цифры
2026-04-23 | ОЦЕНКА: 5 | ЗАДАЧА: хук-пост | ФИДБЕК: -
2026-04-23 | ОЦЕНКА: 2 | ЗАДАЧА: хук-пост | ФИДБЕК: начинается с "В этом посте"
2026-04-24 | ОЦЕНКА: 4 | ЗАДАЧА: хук-reels | ФИДБЕК: норм, можно жёстче
2026-04-25 | ОЦЕНКА: 3 | ЗАДАЧА: хук-пост | ФИДБЕК: снова без цифры
```

**Что агент должен вывести из этого лога:**

Паттерн: 3 из 5 записей — проблема с конкретикой (нет цифры) или с началом фразы.

Новое правило в "Выученные паттерны":
`• Хук всегда содержит конкретную цифру или результат — выявлено 2026-04-25`

## Промпт для ручного анализа feedback.log

Если хочешь запустить анализ вручную:

```
Открой файл ~/.claude/skills/[название]/feedback.log

Проанализируй все записи:
1. Найди повторяющиеся проблемы (3+ упоминания одного паттерна)
2. Выдели паттерны которые точно работают (оценки 4-5)
3. Сформулируй 2-3 новых правила на основе анализа
4. Добавь их в раздел "Выученные паттерны" файла скилла

Покажи что добавил и почему.
```

---

## Важные ограничения

**Не обновлять SKILL.md после каждого запуска автоматически** — только если паттерн повторился 3+ раза. Иначе одна случайная оценка превратится в "новый закон".

**Максимум 10 правил** в разделе "Выученные паттерны". Если больше — объединяй похожие или удаляй устаревшие.

**Периодически чистить feedback.log** — оставлять только последние 30 записей. Старые уже учтены в паттернах.
