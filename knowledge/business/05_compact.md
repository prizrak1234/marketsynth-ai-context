# Команда: /compact

## Что делает

Сжимает контекстное окно сессии. Агент суммирует всю предыдущую историю в краткое резюме и продолжает работу с освободившимся контекстом. Задача не теряется, но детали ранних сообщений сжимаются.

## Разница с /clear и /newchat

| Команда | Что происходит | Задача | Контекст |
|---------|---------------|--------|----------|
| `/compact` | Сжатие истории в резюме | Продолжается | Освобождается ~50-70% |
| `/clear` | Полная очистка истории | Теряется | Сброс до 0% |
| `/newchat` | Checkpoint + новая сессия | Checkpoint сохранён | Сброс до 0% |

## Когда использовать

- `/convolife` показывает 60-80%
- Задача ещё не завершена и переключаться на новый чат рано
- Максимум 3-4 раза за сессию (потом качество падает — делай /newchat)

## Как внедрить в своего агента

### Через CLAUDE.md

Добавь в `CLAUDE.md`:

```markdown
### compact
Триггер: пользователь пишет "compact" или "/compact".

Правила:
- Вызывай /compact когда контекст достигает ~60%
- Не жди автоматического compact на 95% — к тому моменту качество уже просело
- После 3-4 compactions — предложи /newchat (качество деградирует с каждым сжатием)
- Compact сжимает историю, но сохраняет нить задачи

Когда что выбирать:
- compact — контекст >60%, задача продолжается, нужно освободить место
- clear — тема полностью завершена, чистый старт в той же сессии
- newchat — после 3-4 compactions, или при смене темы, или при деградации качества
```

### Промпт для внедрения (скопируй и отправь агенту)

```
Внедри команду /compact в мою систему. Вот инструкция:

Когда я пишу "compact" или "/compact" — сожми контекстное окно.

Правила:
1. Сжимай историю в краткое резюме, сохраняя нить текущей задачи
2. Не жди автоматического compact на 95% — делай на 60%
3. После 3-4 compactions — предложи /newchat (качество деградирует)
4. Перед compact хорошо сделать /checkpoint

Разница с другими командами:
- /compact — сжимает, задача продолжается
- /clear — стирает всё, чистый старт
- /newchat — checkpoint + новая сессия

Добавь это правило в CLAUDE.md агента.
```

## Примеры использования

**Пример 1 — плановое сжатие:**
```
Пользователь: /convolife
Агент: Context: 64% used — ~72k tokens remaining

Пользователь: /compact
Агент: Контекст сжат. Резюме сессии сохранено.
Продолжаем: мы работаем над парсером Instagram Reels,
осталось добавить обработку карусельных постов.
```

**Пример 2 — повторное сжатие:**
```
Пользователь: /compact
Агент: Контекст сжат (2-й раз за сессию).
⚠️ После ещё 1-2 compactions рекомендую /newchat.
```

**Пример 3 — агент предлагает сам:**
```
Агент: Заметил, что контекст на 73%. Рекомендую /compact
или /checkpoint + /newchat если задача завершена.
```

## Связанные команды

- `/convolife` — проверь загрузку перед compact
- `/checkpoint` — сохрани важное перед сжатием (compact может потерять детали)
- `/newchat` — используй вместо compact после 3-4 сжатий
