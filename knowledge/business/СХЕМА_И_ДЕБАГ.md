# 🎓 ОБЪЯСНЕНИЕ ЛОГИКИ

## Extract Command (Нода 2)
**Цель**: Превратить Telegram-сообщение в структурированные данные.

**Вход**:
```json
{
  "message": {
    "text": "/research AI маркетинг"
  }
}
```

**Выход**:
```json
{
  "command": "research",
  "webhookPath": "research",
  "isStartCommand": false,
  "query": "AI маркетинг"
}
```

**Почему это работает**:
- `text.startsWith('/research')` — явная проверка команды
- `text.replace(/^\/\w+\s*/, '')` — вырезаем команду, оставляем запрос
- `isStartCommand` — чёткий boolean для IF-ноды

## Check Command (Нода 3)
**Цель**: Разделить поток на 2 ветки: приветствие vs вызов модуля.

**Условие**:
```
{{ $json.isStartCommand }} == true
```

**Результат**:
- TRUE → Send Start Message
- FALSE → Call Module

**Почему это работает**:
- Проверяется boolean-значение, установленное в Extract Command
- Нет магических строк или undefined-значений

## Call Module (Нода 5)
**Цель**: Отправить POST-запрос к модулю.

**URL**: `https://sarbastn8n.ru/webhook/{{ $json.webhookPath }}`  
**Body**: `{ "query": "{{ $json.query }}" }`

**Пример**:
```bash
POST https://sarbastn8n.ru/webhook/research
Content-Type: application/json

{
  "query": "AI маркетинг"
}
```

**Почему это работает**:
- `webhookPath` уже содержит правильное значение (`research`, `content`, etc.)
- Динамическая подстановка через `{{ }}`

## Extract Response (Нода 6)
**Цель**: Извлечь нужные данные из ответа модуля.

**Вход** (от Call Module):
```json
{
  "success": true,
  "module": "Research",
  "summary": "Проведён анализ: AI маркетинг"
}
```

**Выход**:
```json
{
  "chatId": 123456789,
  "module": "RESEARCH",
  "summary": "Проведён анализ: AI маркетинг"
}
```

**Почему это работает**:
- `$input.item.json` — данные от HTTP Request
- `$input.first().json.chatId` — chatId из предыдущей ноды (Extract Command)
- Обработка разных форматов ответа: `response.summary`, `response.result`, или строка

# 🛠️ ДЕБАГ

## Как проверить Extract Command
1. Откройте ноду Extract Command
2. Нажмите **Execute Node**
3. В **Input** вставьте тестовые данные:
```json
{
  "message": {
    "text": "/research AI маркетинг",
    "chat": {
      "id": 123456789
    }
  }
}
```
4. Проверьте **Output** — должны увидеть:
```json
{
  "command": "research",
  "webhookPath": "research",
  "isStartCommand": false,
  "query": "AI маркетинг",
  "chatId": 123456789
}
```

## Как проверить Call Module
1. Откройте ноду Call Module
2. Убедитесь, что URL: `https://sarbastn8n.ru/webhook/{{ $json.webhookPath }}`
3. Протестируйте вручную через curl:
```bash
curl -X POST https://sarbastn8n.ru/webhook/research \
  -H "Content-Type: application/json" \
  -d '{"query": "тест"}'
```
4. Если вернулся JSON с `summary` — модуль работает!

## Как проверить IF-ноду
1. Откройте Check Command
2. Условие должно быть: `{{ $json.isStartCommand }}` equals `true`
3. Протестируйте с /start → TRUE выход
4. Протестируйте с /research → FALSE выход
