# Шпаргалка: Cron для ИИ-агента

## Синтаксис

```
минута час день_месяца месяц день_недели
```

## Готовые паттерны

```bash
# Каждый день в 9:00
0 9 * * *

# Каждый понедельник в 9:00
0 9 * * 1

# Каждое воскресенье в 10:00
0 10 * * 0

# Каждые 4 часа
0 */4 * * *

# Каждые 30 минут
*/30 * * * *

# По будням в 9, 13 и 17
0 9,13,17 * * 1-5

# Каждую пятницу в 17:00
0 17 * * 5

# 1-е число каждого месяца в 9:00
0 9 1 * *

# Каждый час
0 * * * *

# Дважды в день (9:00 и 21:00)
0 9,21 * * *
```

## Дни недели

```
0 = воскресенье
1 = понедельник
2 = вторник
3 = среда
4 = четверг
5 = пятница
6 = суббота
7 = воскресенье (то же что 0)
```

## Важно: время в UTC

Сервер работает в UTC. Чтобы получить московское время (UTC+3):

| Хочу МСК | Ставлю UTC |
|---|---|
| 6:00 | 3:00 |
| 9:00 | 6:00 |
| 12:00 | 9:00 |
| 18:00 | 15:00 |
| 21:00 | 18:00 |

Проверить: https://crontab.guru

## Команды schedule-cli.js

```bash
# Создать задачу
node dist/schedule-cli.js create "промпт" "cron" CHAT_ID

# Список задач
node dist/schedule-cli.js list

# Пауза
node dist/schedule-cli.js pause ID

# Возобновить
node dist/schedule-cli.js resume ID

# Удалить
node dist/schedule-cli.js delete ID
```
