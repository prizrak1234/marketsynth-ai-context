# Команда: /dream

## Что делает

Запускает "дефрагментацию" памяти агента. Проходит по всем накопленным записям, удаляет устаревшие и дублирующиеся, извлекает паттерны и обобщения из разрозненных наблюдений. Как сон для мозга — наводит порядок в долговременной памяти.

## Когда использовать

- После серии тяжёлых сессий (5+ checkpoint-ов накопилось)
- Раз в неделю как профилактика
- Когда агент начинает путаться в старых фактах
- После крупных изменений в проекте (чтобы устаревшие записи не мешали)

## Как внедрить в своего агента

### Вариант 1 — Через CLAUDE.md (простой)

Добавь в `CLAUDE.md`:

```markdown
### dream
Триггер: пользователь пишет "dream", "/dream" или "консолидируй память".

Действия:
1. Прочитай файл памяти агента (agent-memory.md или аналог)
2. Найди записи старше 30 дней — проверь актуальность
3. Удали дубликаты и устаревшие записи
4. Извлеки паттерны: если 3+ записей об одном и том же — обобщи в одну
5. Сохрани обновлённый файл
6. Отчитайся: сколько записей было, стало, что удалено, что обобщено
```

### Вариант 2 — Через скрипт + Skill

1. Создай скрипт `scripts/dream.sh`:

```bash
#!/bin/bash
# Dream — Memory Consolidation
# Запускает Claude Code для консолидации памяти

echo "🧠 Запуск консолидации памяти..."
echo "Проверяю agent-memory.md..."

# Подсчёт записей до
BEFORE=$(grep -c "^##" ~/obsidian-vault/ClaudeClaw/agent-memory.md 2>/dev/null || echo 0)
echo "Записей до: $BEFORE"
echo "Консолидация запущена. Агент обработает файл."
```

2. Создай skill `~/.claude/skills/dream/SKILL.md`:

```markdown
---
name: dream
description: Consolidate and optimize agent memory files. Trigger when user says "dream", "/dream", or "консолидируй память".
---

# Dream — Memory Consolidation

## Instructions

1. Read the agent memory file (agent-memory.md)
2. For each entry older than 30 days — check if still relevant
3. Remove duplicates and outdated entries
4. If 3+ entries cover the same topic — merge into one generalized pattern
5. Save the updated file
6. Report: entries before/after, what was removed, what was merged
```

### Промпт для внедрения (скопируй и отправь агенту)

```
Внедри команду /dream в мою систему. Вот инструкция:

Когда я пишу "dream" или "/dream" — запусти консолидацию памяти.

Что делать:
1. Открой файл памяти агента (agent-memory.md или аналог)
2. Пройдись по всем записям:
   - Устаревшие (старше 30 дней, разовые находки) — удали
   - Дубликаты — объедини
   - Если 3+ записей на одну тему — обобщи в один паттерн
3. Сохрани результат
4. Отчитайся: было X записей, стало Y, удалено Z, обобщено N

Постоянно хранить: пути к файлам, архитектурные решения, паттерны, правила стиля.
Удалять: разовые наблюдения, временные решения, дубликаты.

Создай skill файл для этого в ~/.claude/skills/dream/SKILL.md
```

## Примеры использования

**Пример 1 — еженедельная консолидация:**
```
Пользователь: dream

Агент: Консолидация завершена.
• Было: 47 записей
• Стало: 31 запись
• Удалено: 12 устаревших (временные пути, разовые баги)
• Обобщено: 4 группы → 4 паттерна
  - 5 записей о форматировании → 1 правило стиля
  - 3 записи о парсинге дат → 1 паттерн обработки
```

**Пример 2 — после крупного рефакторинга:**
```
Пользователь: /dream

Агент: Консолидация завершена.
• Было: 38 записей
• Стало: 24 записи
• Удалено: 14 записей со старыми путями (до рефакторинга)
• Добавлено: 2 новых паттерна из последних сессий
```

**Пример 3 — профилактика:**
```
Пользователь: консолидируй память

Агент: Память в порядке.
• Было: 29 записей → стало: 27
• Удалено: 2 дубликата
• Новых паттернов не обнаружено
```

## Связанные команды

- `/checkpoint` — создаёт записи, которые dream потом консолидирует
- `/newchat` — после dream хорошо начать свежую сессию с чистой памятью
- `/compact` — если во время dream контекст переполнился
