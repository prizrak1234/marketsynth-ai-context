## Виджет AI-чата

Круглая кнопка в правом нижнем углу. По клику — окно чата:
- Заголовок: "AI-консультант"
- Приветствие: "Здравствуйте! Расскажу про тарифы, возможности и условия подключения НейроCRM."
- Сообщения пользователя справа, ответы бота слева
- Индикатор "печатает..." при ожидании
- Адаптивность на мобильных

JavaScript-логика чата:
```
// При инициализации чата
const sessionId = 'web_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9);

// При отправке сообщения
fetch('YOUR_WEBHOOK_URL', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ message: text, sessionId: sessionId })
})
// Ответ бота: response.output
```
