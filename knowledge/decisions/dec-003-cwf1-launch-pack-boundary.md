# DEC-003: CWF.1 Launch Pack Boundary

**Date:** 2026-07  
**Status:** Active

## Context

Commercial track needs a sellable, bounded deliverable — not open-ended platform features.

## Decision

**CWF.1 Launch Pack** includes exactly:
validation, verdict, risks, audience, positioning, offer, launch plan, 3 Telegram posts, 1–3 visuals, one real Telegram publish, persisted project history.

Workflow:
```
Idea → Research → Evidence → Verdict → Offer → Launch Plan
→ 3 Content Assets → Optional Visuals → Telegram Approval → Real Publication → Delivery Evidence
```

## Alternatives considered

- Full platform journey in v1 — rejected (scope)
- Chat-only deliverable — rejected (not sellable)

## Consequences

- Out of scope: skill marketplace, CRM, Ads, billing, multi-channel, new Home redesign
- Partial delivery documented honestly in CWF-SKILL-INTEGRATION-GAPS
- Every PR evaluated against commercial-product-directive

## Verification

Owner browser golden path + real Telegram send
