```
[Видео URL] → [ScrapeCreators/Скачивание] → [Транскрибация Whisper]

    → [RAG-запросы] → [Генерация нового контента]
```

## 6. Повторяющиеся паттерны

### 6.1 Архитектура AI-агента

```
┌─────────────────────────────────────────────────────────────┐
│                     AI AGENT PATTERN                        │
├─────────────────────────────────────────────────────────────┤
│  [Trigger] → [Router] → [AI Agent] → [Tools] → [Output]    │
│                                                             │
│  • Trigger: Telegram, Schedule, Webhook                    │
│  • Router: Switch (text/voice/image)                       │
│  • AI Agent: GPT-4.1 / Claude Sonnet                       │
│  • Memory: Redis / Postgres                                │
│  • Tools: Workflow tools, API calls                        │
│  • Output: Telegram, Google Sheets, DB                     │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 Паттерн парсинга соцсетей

```
[Schedule Trigger] → [ScrapeCreators API] → [DataTable Check] 
    → [Split Out] → [Loop] → [Транскрибация] → [AI-анализ] 
    → [Сохранение в БД] → [Уведомление Telegram]
```

### 6.3 Паттерн RAG-системы

```
[YouTube Channel] → [Транскрибация] → [Embeddings OpenAI] 
    → [Supabase Vector Store] → [AI Agent с поиском] 
    → [Ответ на вопросы по базе знаний]
```

### 6.4 Паттерн генерации видео

```
[Форма/Telegram] → [AI-генерация промпта] → [Video API (VEO/Sora)] 
    → [Ожидание] → [Получение результата] → [Google Drive] 
    → [Уведомление]
```

## 7. Пробелы и недостающие компоненты

### 7.1 Критические пробелы

| Компонент | Описание | Приоритет |
|-----------|----------|-----------|
| **Яндекс.Дзен** | Нет никакой интеграции | 🔴 Высокий |
| **Парсер VK** | Только чат-бот, нет парсинга постов | 🔴 Высокий |
| **Кросс-постинг** | Нет единого механизма публикации во все каналы | 🟡 Средний |
| **Аналитика охвата** | Нет сбора статистики по публикациям | 🟡 Средний |

### 7.2 Частично реализовано

| Компонент | Что есть | Чего не хватает |
|-----------|----------|-----------------|
| **YouTube Shorts** | Vizard для клипов | Авто-публикация Shorts |
| **Instagram** | Парсинг и анализ | Авто-публикация постов |
| **TikTok** | Анализ контента | Загрузка видео |
| **Telegram** | Отличное покрытие | - |

### 7.3 Технические ограничения

| Ограничение | Описание | Решение |
|-------------|----------|---------|
| **ScrapeCreators** | Платный API, лимиты | Кэширование, ротация ключей |
| **Rate limiting** | Соцсети блокируют частые запросы | Очереди, задержки |
| **Видео-хранение** | Большие файлы | Google Drive, S3 |
| **Обработка в реальном времени** | Долгая генерация видео | Асинхронная архитектура |

### 8.2 Компоненты системы

#### 8.2.1 Ingest Layer (Сбор контента)

```yaml
YouTube Agent:
  - Парсинг каналов (ScrapeCreators)
  - RSS-ленты
  - Транскрибация видео
  - Извлечение Shorts

Instagram Agent:
  - Парсинг профилей
  - Получение Reels
  - Анализ хэштегов
  - Мониторинг конкурентов

TikTok Agent:
  - Парсинг профилей
  - Поиск по хэштегам
  - Анализ трендов

Telegram Agent:
  - Мониторинг каналов
  - RSS-агрегация
  - Форвард сообщений

VK Agent (NEW):
  - Парсинг постов (требует разработки)
  - Мониторинг групп
  - Сбор статистики

Дзен Agent (NEW):
  - Парсинг статей (требует разработки)
  - Анализ трендов
```

#### 8.2.2 Process Layer (Обработка)

```yaml
Content Pipeline:
  1. Transcription:
     - Whisper API (OpenAI)
     - Локальные модели (если требуется)
  
  2. Analysis:
     - GPT-4.1 для суммаризации
     - Claude для глубокого анализа
     - Ключевые моменты
     - Тональность
  
  3. Generation:
     - Сценарии (GPT-4.1)
     - Промпты для видео
     - Заголовки/описания
  
  4. Repurposing:
     - Длинное → Короткое (Vizard)
     - Видео → Текст
     - Текст → Карусели
     - Контент для разных платформ
  
  5. Media Generation:
     - VEO 3 / Sora (видео)
     - Nano Banana / Gemini (изображения)
     - ElevenLabs / TTS (голос)
```

#### 8.2.3 Distribution Layer (Распространение)

```yaml
Publishing Hub:
  - Telegram: Полная поддержка
  - VK: Требует разработки постинга
  - Дзен: Требует разработки
  - WordPress: Есть workflow
  - RSS: Есть workflow
  - Webhook: Для кастомных интеграций
```

### 8.4 API Endpoints (предлагаемые)

```
POST /api/content/ingest
  - Источник: youtube, instagram, tiktok, telegram, vk, zen
  - URL или ID контента
  - Опции обработки

POST /api/content/repurpose
  - ID исходного контента
  - Целевой формат: short, article, carousel, script
  - Параметры генерации

POST /api/content/generate
  - Тип: video, image, text
  - Промпт
  - Модель: veo3, sora, seedance, gemini

GET /api/content/search
  - RAG-поиск по всей базе контента
  - Фильтры по источнику, дате, тегам

POST /api/content/publish
  - Целевая платформа
  - ID контента
  - Расписание (опционально)
```

## 9. Приоритеты разработки

### 9.1 Фаза 1: Базовая инфраструктура (2-3 недели)

|--------|----------|------------|

| 4. Content DB | Структура хранения контента | Airtable/Supabase |

### 9.2 Фаза 2: Расширение функционала (3-4 недели)

| Задача | Описание | Зависимости |
|--------|----------|-------------|
| 1. Авто-публикация VK | Постинг в группы | VK Parser |

## 10. Заключение

### 10.1 Ключевые выводы

1. **Сильная база для YouTube, Instagram, TikTok, Telegram** — готовые workflow можно переиспользовать
2. **VK частично покрыт** — есть чат-бот, но нет парсинга контента
3. **Яндекс.Дзен полностью отсутствует** — требуется разработка с нуля
4. **Отличная инфраструктура генерации** — VEO 3, Sora, Seedance, Nano Banana
5. **Паттерны унифицированы** — можно создать единую платформу

### 10.2 Рекомендации

1. **Использовать существующие workflow как шаблоны** — не переписывать, а адаптировать
2. **Создать единый Data Model** — все контенты в одной структуре
3. **Разработать VK и Дзен парсеры в приоритете** — критические пробелы
4. **Инвестировать в RAG-систему** — уникальное конкурентное преимущество
5. **Автоматизировать кросс-постинг** — максимальная выгода от контента

### 10.3 Оценка ресурсов

| Компонент | Сложность | Время | Зависимости |

| VK Parser | Средняя | 1 неделя | - |

| Unified API | Низкая | 3 дня | Парсеры |
| Кросс-постинг | Средняя | 2 недели | API |
