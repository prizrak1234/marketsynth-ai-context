# Presentation Architecture Methodology

Adapted presentation planning methodology for Marketsynth specification contracts.

## Principles

1. **Specification only** — output is a structured plan, not rendered slides.
2. **One primary message per slide** — split dense content rather than compress.
3. **Evidence preserved** — claims retain source references; unsupported claims stay visible.
4. **Provider-neutral** — theme and layout recommendations work across future renderers.
5. **Accessibility by design** — contrast, alt text, chart descriptions required.

## Narrative planning

- Match arc type to presentation type and audience.
- Do not invent missing evidence in narrative structure.
- Financial or investor claims require explicit assumptions and sources.

## Slide density

- Limit supporting points and content blocks per slide.
- Excessive density triggers human review findings.

## Theme selection

- Select theme family based on audience, content, and brand constraints.
- Dark and colorful themes require contrast review.
- No copied external CSS or remote font dependencies.

## QA checklist

- Slide sequence contiguous and unique IDs.
- Charts reference data — no invented values.
- CTA aligned with presentation objective.
- No rendering authorization in output.
